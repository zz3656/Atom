## 🎉 博客搭建成功

欢迎使用 **Atom 博客**！这是一个基于 [Astro](https://astro.build) 构建的轻量级静态博客。

## ✨ 博客特性

| 特性 | 说明 |
|------|------|
| ⚡ **零 JavaScript** | 页面输出纯 HTML，性能极致 |
| 🌙 **暗黑模式** | 一键切换，自动记忆用户偏好 |
| 📱 **响应式设计** | 手机、平板、桌面完美适配 |
| 📝 **Markdown 写作** | 原生 Markdown 支持，代码高亮 |
| 🔍 **SEO 优化** | 内置 RSS、Sitemap、Open Graph |
| 🚀 **一键部署** | GitHub Pages + Actions 自动部署 |

## 📝 如何写文章

在 `src/content/blog/` 目录下创建 `.md` 文件即可发布新文章。

```markdown
---
title: 文章标题
description: 文章描述
pubDate: 2025-09-14
tags: [标签1, 标签2]
---

正文内容...
```

## 🛠️ 技术栈

- **[Astro](https://astro.build)** — 静态站点生成器
- **TypeScript** — 类型安全
- **GitHub Pages** — 免费部署
- **GitHub Actions** — 自动 CI/CD
